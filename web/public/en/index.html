FIELD MANUAL

Three-step deployment

For Forge 1.20.1 and TACZ. Fully exit the game before updating so the old ZIP file is no longer locked.

  1. 01

    Get the release

    Download Modern Warfare 4-<version>.zip from GitHub Releases.

  2. 02

    Place it in TACZ

    Put the ZIP in the instance's .minecraft/tacz/ directory. Do not extract it.

  3. 03

    Reload

    Start the game or run /tacz reload. Restart the client after replacing an existing pack.
