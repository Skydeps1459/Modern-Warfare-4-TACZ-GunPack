# Modern Warfare 4 1.12.0-Release

> 是的孩子们 我们又多了N个BUG

## 新增内容

新增 HK G28 精确射手步枪

- 10 发标准弹匣 扩容弹匣为 20 / 30 发 半自动射击
- 使用 7.62x51mm 弹药 可在枪匠台合成
- 归类为射手步枪 完整的检视 换弹 扩容检视与三段刺刀近战随机播放
- 二级扩容空仓换弹带第二弹匣插入动作 开火与换弹音效独立
- 默认装配原厂战术枪托 可在枪匠台自由更换其他枪托

## Bug 修复

- **G28 动画回退默认**：G28 在部分环境下整套动画变成默认基础动作 现在全部动作正常播放
- **G28 扩容动画误判**：未装备扩容弹匣时换弹与检视却播放扩容动作 现在按实际弹匣等级正确分流
- **G28 检视弹匣子弹**：弹匣打空仅剩膛内一发时检视仍显示弹匣内有子弹 现在空弹匣检视不再显示子弹
- **G28 二级扩容战术换弹**：非空仓的战术换弹也会冒出第二个弹匣 现在仅空仓换弹才出现第二弹匣
- **G28 换弹节奏**：换弹动作早已结束却仍在等待冷却 现在动作收尾即可再次换弹与开火
- **G28 弹药数值延迟**：换弹时弹匣已装回但右下角弹药数过一会才跳变 现在数值在插匣到位时同步更新
- **G28 特殊弹药弹匣消失**：装备穿甲 空尖 燃烧等特殊弹药时整个弹匣不显示 现在弹匣正常显示
- **G28 特殊弹药换弹动作**：装备特殊弹药时换弹与检视播放标准弹匣动作而非扩容动作 现在与二级扩容弹匣动作一致

## 其他变更

- G28 开火音效更换为更干脆的新版音源
- G28 手持姿态微调 左右手锚点更贴合枪身
- G28 近战间隔由 0.45 秒缩短至 0.3 秒 连续枪托攻击更跟手
