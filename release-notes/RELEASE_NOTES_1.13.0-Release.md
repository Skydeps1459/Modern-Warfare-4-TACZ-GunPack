# Modern Warfare 4 1.13.0-Release

> M4A1秽土转生 但音容犹在

## 新增内容

新增 URGI 突击步枪

- 30 发标准弹匣 扩容弹匣为 40 / 50 / 60 发 支持全自动与半自动
- 使用 5.56x45mm 弹药 射速 750 发每分钟
- 默认装配原厂战术枪托 可更换瞄具 枪托 握把 枪口 扩容弹匣与镭射

## 其他变更

- M4A1 已从枪包下架 原有的存档内 M4A1 将不再显示

## 安装

> **⚠️ 重要提醒：要求 1.4.0 及以上版本的 TACZ: Arcana 模组**

将 `Modern Warfare 4-1.13.0-Release.zip` 放入 `.minecraft/tacz/`，不要解压
更新已加载的枪包时请先完全退出游戏
